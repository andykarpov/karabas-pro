# Команды AT+KARABAS= прошивки AVR

AVR принимает команды по UART: разъём J6 «AVR UART» (1 VCC 5 В, 2 GND, 3 AVR_TX = PD1,
4 AVR_RX = PD0), 115200 8N1 (у AVR 117647, +2,1 %: с адаптером на 115200 работает). Набор и
синтаксис — как у порта управления Karabas Go (`karabas-go-firmware`, README, «USB serial»),
насколько это есть у Профи. С переходником `tools/usb-ps2-bridge` UART виден как USB serial.

Нужно, чтобы стенд мог работать с платой без клавиатуры, мыши и джойстика: нажимать клавиши
(в том числе горячие и в OSD), двигать мышь, жать кнопки джойстика и выставлять пункты меню.

- Строка — `AT+KARABAS=<команда>`, конец — CR, LF или CR LF; префикс в любом регистре, строки
  без него пропускаются. Длина строки — до 83 символов.
- Ответ — строки `+KARABAS:...`, затем `OK` или `ERROR`.
- Команды, которые идут во времени (`key`, `type`, `pad`, `mouse`, `click`), отвечают `OK`,
  когда всё отправлено; следующая строка читается после этого (приёмный буфер — 128 байт, поэтому
  слать по одной строке и ждать ответа).
- Клавиши идут в очередь клавиатуры PS/2 как уже разобранные коды: горячие клавиши, OSD и
  матрица ZX видят их как с клавиатуры. Мышь — отчётами в очередь мыши PS/2, джойстик —
  кнопками поверх настоящего (оба режима, Kempston и Sega).

| Команда | Действие |
| --- | --- |
| `version` | `+KARABAS:<сборка AVR>;pro;<сборка FPGA>` |
| `state` | `+KARABAS:osd;<меню открыто>;<popup>` |
| `key:<клавиши>` | нажать и отпустить: клавиши через пробел, сочетание через `+` (`ctrl+alt+del`, `menu+f3`, `enter`); 100 мс нажато, 40 мс пауза |
| `type:<текст>` | набрать текст (печатный ASCII, раскладка US; заглавные и символы — с Shift); 60 мс нажато, 40 мс пауза |
| `hold:<сочетание>` / `release` | держать клавиши до `release` или следующего `key` / `type` / `hold` / отпустить всё: клавиши, кнопки мыши и джойстика |
| `sync` | `OK` (команды и так отвечают по завершении) |
| `mouse:<dx>,<dy>[,<кнопки>]` | движение как у USB-мыши (вниз — плюс, до ±3000), по 127 отсчётов на отчёт через 10 мс; кнопки: бит 0 левая, 1 правая, 2 средняя; не указаны — остаются прежние |
| `click[:left\|right\|middle]` | щелчок (60 мс), по умолчанию левой |
| `pad:[0:]<кнопки> ...` / `padhold:[0:]<кнопки>` | нажать и отпустить кнопки джойстика (100 / 40 мс), через пробел, вместе через `+`: `pad:up up+b` / держать до `release` или следующего `pad`. Кнопки: `up down left right start a b c x y z mode`; огонь Kempston — `b`, второй — `c` |
| `osd` | все пункты: `+KARABAS:item;<номер>;<имя>;<значение>;<максимум>` |
| `osd:<пункт>` / `osd:<пункт>=<значение>` | один пункт / выставить (как пункт меню или горячая клавиша: сохраняется в EEPROM, всплывает popup). Пункт — имя или `#<номер>` |
| `reset` / `magic` | сброс / Magic (как кнопки платы) |

Пункты: `rombank` (0..3 банк, 4 +3e), `turbofdc`, `covox`, `psg_mix` (0 ACB, 1 ABC, 2 моно),
`psg_type`, `video`, `vsync`, `turbo` (0..максимум FPGA), `swap_fdd`, `joy_type` (0 Kempston,
1 Sega), `joy_mode` (0..4), `screen`, `divmmc`, `nemoide`, `keyboard` (0 Spectrum, 1 Profi XT),
`pause`, `mouse_swap`, `lang` (0 en, 1 ru, 2 ua), `menu` (OSD-меню открыто).

Имена клавиш: `a`..`z`, `0`..`9`, `f1`..`f12`, `kp0`..`kp9`, `esc enter space tab bs
backspace del delete ins insert home end pgup pgdn up down left right caps ctrl lctrl rctrl
shift lshift rshift alt lalt ralt altgr gui win lgui rgui menu prtscr scroll pause num minus
equal lbracket rbracket backslash semicolon quote grave comma dot slash kpenter kpplus kpminus
kpdot`. Горячие клавиши Профи — с `menu` (или `win`, или `ctrl+alt`): `menu+esc` открывает меню.

Отличия от Karabas Go: одна колонка джойстика (порт `0:` можно не писать), нет колеса мыши,
нет файловых команд; HID usage (`0x29`) вместо имени не принимается.

Проверка — хост-стенд `firmware/src/avr/host_test/run.sh`: сценарий `c` шлёт команды, сценарий
`d` делает те же нажатия, джойстик и мышь моделями устройств; пакеты HID линка у них совпадают,
ответы и значения меню (`SETVAL`) сверяются. Мутации в `sim/run_avr_link.sh`.

Прошивка: `src/at_cmd.c`; UART — `hal.c` (приём по прерыванию в кольцо на 128 байт). Flash
29198 из 32768 (было 23740).
